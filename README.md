## 🚀 Featured Project — NanoLink

**[NanoLink — Distributed URL Shortener](https://github.com/shyamprakash534/nanolink1)**

A Go-based distributed URL-shortening system designed around fast redirect resolution, caching, rate limiting, asynchronous analytics, observability, and cloud deployment.

**Technology:** Go • PostgreSQL • Redis • ClickHouse • Docker • Terraform • AWS • Prometheus • Grafana • GitHub Actions

**Engineering highlights**
- Fast redirect path with Redis caching and Bloom-filter rejection
- Distributed token-bucket rate limiting using Redis/Lua
- Redis Streams for asynchronous analytics ingestion
- PostgreSQL for persistent URL metadata
- ClickHouse architecture for analytics workloads
- Stateless API design for horizontal scaling
- Docker Compose for local distributed development
- Terraform configuration for AWS infrastructure
- Prometheus-compatible metrics and Grafana monitoring
- Automated testing and Docker image builds with GitHub Actions

**Live deployment:** [nanolink1.onrender.com](https://nanolink1.onrender.com)

> The current public deployment runs the core URL-shortener service; ClickHouse analytics storage is disabled when a production ClickHouse instance is not attached. The repository still contains the distributed analytics architecture and local configuration.
